# Scope and evidence limits

- Rules express fictional commercial preferences. No jurisdiction, enforceability or legal correctness claim is made.
- Inputs are bounded, text-native, numbered sections: one base and up to two A1/A2 amendments. PDF, DOCX, OCR, tracked changes and arbitrary natural-language precedence are unsupported.
- The scripted grammar is narrow. Heading search, canonical-form scanning and full supplied-text coverage do not establish exhaustive semantic review. Qualifying exceptions and unsupported wording need human interpretation.
- Literal references and explicit replacement chains have bounded depth. Filenames/dates never infer priority. Missing referenced evidence stays unknown; competing amendments hand off.
- Exact quotes and versioned edit ranges enforce provenance and byte preservation. They do not establish legal entailment, semantic correctness or minimum drafting impact.
- The default provider is scripted with zero model calls. The native adapter was exercised through a loopback fake HTTP server only. Real model inference, model quality, model installation and token cost benchmarking remain unexecuted.
- All 42 cases and labels are developer-authored with AI assistance. Thirty frozen cases have now been scored; they share canonical supported sentences, are not lawyer-certified and are not a blind expert benchmark. The author saw labels while constructing source/oracle; freezing does not eliminate this exposure. The driver keeps labels outside actor tools and grades only after all outputs are frozen, but runs in the same OS process.
- Finite gold spans, atom labels, localized edits and document bytes define outcome correctness. Exact gold overlap is not semantic entailment; alternative valid phrasing or spans can fail. Unknown findings may include additional genuine quotes as the frozen rubric allows. Literal quote fidelity and gold-supported meaning are separate metrics.
- The fixed keyword baseline intentionally abstains on reference/amendment meaning and missing obligations. It shares host guards and review authority; honest abstention can still be an outcome failure. Scripted 30/30 versus keyword 16/30 exact cases and 120/120 repeat comparisons apply only to these authored deterministic variants. Correct required handoffs count as exact cases and must not be presented as automatic business completion.
- Normalized repeat equality excludes SQLite internals and cannot establish raw-state integrity. Runner v2 separately gates all 180 planned runs and persists full plan/start/result/partial evidence. Main verified all 180 saved raw outcomes as well as 120 normalized repeat comparisons. The first producer attempt remains incomplete: 70 completed records, one start-only unfinished receipt and 109 unattempted identities. Later complete evaluation evidence does not repair that failed attempt. Local flush/fsync does not establish OS power-loss or distributed durability, and an unwritable/full filesystem or uncatchable process termination can prevent the final diagnostic write; prior artifacts remain available for incomplete accounting.
- Approval is local and all-or-none. Reviewer labels are annotations, not authenticated identity. The OS owner can tamper with SQLite/files; this is not a sandbox or tamper-proof audit system.
- Source supports sequential resume and repeat approval. Independent Windows checks on current M3 application source passed all 147 tests, including fake HTTP and recovery suites, both CLI regressions and quickstart approval/idempotence/handoff checks. Concurrent actors/reviewers, distributed execution and cross-version resume are not claimed.
- Earlier worker measurement wrappers failed; their historical errors and missing RAM/process/time coverage remain unknown where unmeasured. Main's independent application and saved-evaluation checks passed, but native peak RAM was not measured in those main slices. Final M3 package acceptance awaits documentation review. Hosted CI, Linux/macOS runtime, real Ollama inference, legal accuracy, production adoption, business impact, publication and deployment remain unexecuted or unmeasured.
